JWT in the header

POST /api/auth/register/ and POST /api/auth/token/ return access and refresh. Send Authorization: Bearer <access>. Access lasts 30 minutes; refresh lasts 14 days and is not rotated.

Paginated lists

Forum collection routes use DRF page-number pagination: ?page=, 20 items, envelope count / next / previous / results. Nested /posts/{id}/comments/ is a raw array.

Trailing slashes

Every path in this spec ends with /. Local server is Wrangler at http://localhost:8787. Django admin stays at /admin/login/ after bootstrap.

Quick start

With npm run dev up, bootstrap D1 once, then register a user and hit a protected route. 

curl -X POST http://localhost:8787/api/_ops/bootstrap/ \
  -H "X-Ops-Token: chili-dev-ops-token"

curl -X POST http://localhost:8787/api/auth/register/ \
  -H "Content-Type: application/json" \
  -d '{"username":"pepper","email":"pepper@chili.example","password":"supersecret"}'

curl http://localhost:8787/api/profiles/me/ \
  -H "Authorization: Bearer $ACCESS"

POST /api/auth/token/refresh/ public Refresh → new access token
GET PUT /api/profiles/me/ JWT Writable: bio, avatar_url

GET /api/forum/posts/ JWT write Filter ?category=<slug>
GET POST /api/forum/posts/<id>/comments/ JWT write GET is an unpaginated array
POST /api/_ops/bootstrap/ X-Ops-Token Migrate, seed, ensure admin
